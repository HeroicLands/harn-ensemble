A Foundry VTT module holding over a thousand ready-made NPCs for the Hârn
setting — pre-generated characters of many occupations and abilities, there to
be pulled into a game as it needs them rather than rolled up at the table.

## Two systems, one module

Most modules serve one game system. This one serves two, and ships a pack for
each:

| Pack            | Type         | System               |
| --------------- | ------------ | -------------------- |
| Actors (`hm3`)  | Actor        | HârnMaster 3         |
| Actors (`sohl`) | Actor        | Song of Heroic Lands |
| Journals        | JournalEntry | Any                  |

Both Actor packs are built from the same cast, expressed in each system's own
mechanics, so an NPC can be dragged straight onto the canvas under either. The
Journals pack carries the descriptive entry for each character and declares no
system at all — a table running neither of the above can still read the whole
roster and build actors to suit whatever it plays.

## Installing

In Foundry, open **Add-on Modules → Install Module** and paste this manifest
URL:

```text
https://github.com/HeroicLands/harn-ensemble/releases/latest/download/module.json
```

Foundry checks that address for updates from then on.
